# References
This document catalogs the shared reference files the workflows take as inputs, along with their sources. A workflow input documented as `From references.` takes the file listed here under the same name. Index files - `ref_fai`, `*_vcf_idx` and the like - are not listed separately; each sits beside the file it indexes. Supply every file as a workflow input, which on Terra means workspace data.

The Path column gives the copy used to build the released callsets. The `gcp-public-data--*` and `gatk-sv-resources-public` buckets are publicly readable, but most other paths are lab-internal Terra buckets that are not. Outside the lab, fetch each file from its Source, which is its public origin, and host it in your own bucket.
